P2F-001：依赖树存在高危/严重漏洞

类别
安全 / 依赖供应链
位置
bun.lock；具体漏洞由 Bun audit 根据 workspace 依赖路径报告

按 workspace 确认可达路径和发布产物；升级含修复版本，必要时使用兼容 override，重新生成 bun.lock。
验证方式

0.99

否；若发布策略要求零 high/critical，则应升级为发布阻断条件。
