1. 交付结论

结论：第二批已完成 San 结构适配、合同测试、相邻回归修正和包级全量验收。所有生产改动均可由明确的上游发布提交追溯；没有混入 RPC v3、MCP 协议迁移、Browser 发现重构或凭证缓存重构。
  • 交互 TUI 与 JSON 输出默认视为已提交：非空 partial text 之后不再自动重放，避免用户看到重复文本。
  • text print 在每个 prompt 期间标记文本尚未提交，瞬态错误与账号策略拒绝可安全重放；正常结束、异常和多 prompt 路径都会恢复状态。
  • 工具调用、图片和未知/未来 server-tool 内容始终不可重放；Advisor 不借用 print text 的缓冲语义。
  • Z.AI 仅在首层解析结果为字符串时尝试第二层 JSON；结构化搜索结果进入 sources，不再泄漏到 answer，普通文本仍保留。
  • PUPPETEER_EXECUTABLE_PATH 现在优先于系统浏览器发现；所有共享非交互子进程携带 AGENT=1。
  • Cursor 与 Devin 在没有残留协议帧时直接持有新 chunk/view，避免每个稳态读取都执行 Buffer.concat；协议字节与输出行为不变。
