Runner Probe 可观测

Native 215,723,578 prompt tokens / $132.760592；Steady 68,469,864 prompt tokens / $69.696。固定价格表推导 Prompt 下降 68.3%、估算成本下降 47.5%。

4. 已完成实现

  • Segment 正确性：递归 Segment 保留原始用户意图，并从上一个分段边界继续覆盖。
  • Digest 稳定性：临时请求错误和结构缺失会有限重试；usage 通过响应观察器记录，不改写生产请求路径。
  • 缓存前缀：同一工具循环内冻结 ContextPlan 字节，避免每次 provider boundary 重写前缀。
  • 维护抖动：无进展的 Segment 维护不会在每次 provider boundary 重复触发。
  • Probe：区分 Agent、TurnDigest、Compaction 请求，记录 usage、缓存、active/raw context、Segment 与 Compaction 事件。
  • 可诊断性：/context 展示 session ID、session 文件、Probe 文件与累计缓存读取率；Prompt 口径为 input + cache read + cache write。
  • Benchmark：实现随机配对、严格工具白名单、隐藏 verifier、质量先行汇总、基础设施整对失效与一次共同重跑、bootstrap CI、费用预检及可复现 provenance。
  • 凭证隔离：付费运行只从 stdin 读入 mode-specific runtime key，在内存中注册并对 artifact 脱敏；拒绝旧环境变量传输路径。
