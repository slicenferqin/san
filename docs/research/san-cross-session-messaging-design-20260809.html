Architecture Decision · 2026-08-09

San 原生跨会话消息

让同一操作系统用户下、不同仓库或 worktree 中运行的独立 San 顶层会话互相发现、寻址和收发消息；沿用现有 hub/IrcBus 语义，不依赖 Claude Code。

same machinesame userlive sessions onlySan-native

结论

发现平面

新增用户级 peer broker，固定于 San 全局运行目录。项目级 daemon broker 无法跨仓库发现，因此不复用其寻址域。

消息平面

NDJSON over Unix domain socket / Windows named pipe。broker 绑定连接身份、路由消息并等待接收端投递回执。

代理体验

hub list/send/wait/inbox 同时覆盖本进程代理和远端 San 会话；远端地址为 san:<12 hex>。

架构

进站路径

socket message
  → broker validates + binds sender
  → recipient client.deliver(message)
  → IrcBus.deliverExternal(...)
  → waiter | idle wake | busy aside | inbox
  → delivery ack

出站路径

hub send to san:…
  → CrossSessionClient.send(...)
  → broker exact-target route
  → recipient delivery outcome
  → injected | woken | failed

AgentSession auto-reply
  → IrcBus external sender fallback

关键协议

领域决策原因 / 不变量
地址san:<12 lowercase hex>每个运行时唯一；sessionId 仅作元数据，同一 transcript 被打开两次也不冲突。
注册范围根 main 会话本进程 subagent 继续由 AgentRegistry/IrcBus 管理；不制造第二套子代理拓扑。
可见范围同机、同 OS 用户、跨 cwd不引入远端 relay、账号授权或网络暴露。
送达语义在线、单次、带接收端回执无持久离线邮箱；断连后精确发送失败，不假装已排队。
身份broker 以已认证 socket 为准忽略客户端自报 sender，禁止伪造来源。
回复replyTo 保留；from 为远端地址现有 from-filtered wait 和 await:true 无需新语义。
故障下一次请求重连并重新注册broker 重启不要求 San 会话重启；本地 hub 始终可用。
生命周期最后连接关闭后延迟退出无常驻 daemon 成本；防止快速重连造成反复拉起。

信任与安全边界

必须成立

  • 运行目录 0700；token 与 socket 0600。
  • 认证后才注册；一条连接只能代表一个 peer。
  • 请求、帧和消息体有固定字节上限。
  • 畸形或超限输入 fail closed。
  • socket 关闭立即移除 peer，并失败所有关联 pending ack。

内容不可信

  • 跨会话文本始终标记为代理提供的协调输入。
  • 绝不提升为 user/system 指令。
  • 只暴露会话元数据，不分享 transcript、密钥或工作区文件。
  • 地址只能来自 hub list；模型不得猜测。

Hub 兼容策略

list

合并本地 registry 与 broker roster。远端条目携带 scope、sessionId、cwd、branch、status 和 activity。

send

本地 ID 走 IrcBus；san:* 走 transport；all 对两个集合去重并 fan-out。

wait / inbox

远端 ingress 进入同一 IrcBus mailbox/waiter，保留消息 ID、时间戳和 replyTo。

自动回复

AgentSession 的中途 auto-reply 仍调用 IrcBus。若目标为 san:* 且本地 registry 无该 ID，IrcBus 使用当前 CrossSessionClient 作为外部 sender。注册 disposer 采用所有权检查，旧会话释放不会清除新会话路由。

启用与降级

crossSession.enabled 默认开启，但默认 SDK/headless 根会话不应隐式启动全局 broker。交互式顶层 San 自动注册；headless SDK 只有显式配置该设置时注册。transport 初始化失败仅记录 warning，进程内 hub 保持原行为。

验证门槛

层次证明
Transport contract两个独立 client、不同 cwd：互相发现；直发恰好一次；准确 injected/woken；回复关联；断连剔除；后续发送失败；broker loss 后重连。
IrcBus contract远端消息满足 from-filtered waiter；本地目标优先；外部 sender 回退；sender disposer 所有权安全；本地 IRC 回归不变。
Hub integration混合 roster、远端精确发送、广播 fan-out、await:true、无远端时的 wait liveness。
Worker-host smokesan --smoke-test 从 CLI host 拉起 peer broker worker，适用于 source、bundle 与 compiled binary。
Real process smoke两个独立 Bun 进程连接同一隔离 runtime，跨不同 cwd 往返消息并在一端退出后观察 roster eviction。

明确不做

无远端网络

不监听 TCP，不跨机器，不承担身份账号体系。

无离线邮箱

broker 不持久化消息，不恢复已关闭会话。

无 transcript 共享

仅传协调消息和最小运行元数据。
