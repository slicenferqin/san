1. 目标与边界

主目标：宿主拥有执行真相

  • 每个逻辑任务绑定稳定的 scope、objective contract、strategy 与 assignment 身份，名称变化不能绕过重复检测。
  • 进展必须落到宿主可验证事实：状态 revision、typed evidence、provider terminal receipt、任务 heartbeat/cursor。
  • 无进展、重复轮询、Provider 连续失败和重复派发触发确定性动作，而不是继续消耗模型回合。
  • 完成、阻塞、需要用户、运行时故障必须由宿主状态机落盘，压缩摘要和子 Agent 文本不能改写目标。

配套目标：会话级子代理路由

  • 通过 /subagent 为当前会话的 @task 子代理指定模型与 effort。
  • 覆盖写入 branch-aware 会话日志；恢复、分叉、清除保持正确。
  • 不污染主代理模型，不修改全局或项目配置，不强制改写专家 Agent。

该能力已独立提交，适合作为支撑执行实验的配套交付，不是 runaway recovery 的核心依赖。
