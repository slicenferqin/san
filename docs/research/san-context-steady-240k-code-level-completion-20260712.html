2. 本轮发现并修复的生产缺口

Fallback-only 在大窗口模型上会先 hard-pressure，而不是先维护上下文

请求计划在 pre-prompt compaction 之前构建；fallback digest 又不能授权 raw coverage。历史增长到 burst ceiling 时，旧实现会直接持久化拒绝并抛错，方案 Step 7 中的 promotion / compaction 没有机会运行。

新路径先做一次不持久化的 preflight；hard pressure 时在用户安全边界尝试模型升级，再运行用户配置的 context maintenance，并针对改写后的 active context 重建 ContextPlan。只有两种恢复均失败时，才沿用原有 fail-closed 拒绝、audit 与 prompt 持久化合同。

1. Preflight
构建但不写 hard audit
2. Promote
尝试更大 context model
3. Maintain
按配置执行 compaction / handoff
4. Rebuild
基于改写后的 active context
5. Fail closed
仍超限才拒绝并保留证据

Status 与 plan audit 仍可能对同一请求算出不同 token

provider usage anchor 包含上一轮 ephemeral plan，新请求却会用当前 plan 替换它；继续复用旧 anchor 会重复计算已退休的 plan。另一个偏差来自 compactionSummary：raw estimator 只统计 summary 本文，而 provider 实际发送带安全边界的 wrapper。

active ContextPlan 现在统一按 convertToLlm 后的 provider-wire message 估算；provider projection、stored estimate 与 status 都消费同一 materialized snapshot。non-steady 路径仍保留原有 provider-anchor 行为，避免扩大改动面。

3. 新增生产路径合同

合同 真实路径 通过证据
20-turn / LLM digest 真实 AgentSession.prompt()、mock provider、真实 post-turn digest orchestration；第 10 轮执行 persisted reload。 20 provider calls、20 个非 fallback digest、至少 4 个 checkpoint；无 compaction；raw stored tokens 超过 16K 时 final wire 仍更小，旧 raw marker 只保留最近有界窗口。
20-turn / fallback-only LLM digest 关闭、fallback 不获得 coverage authority、模型窗口 500K、ContextPlan burst 24K、普通 compaction threshold 故意设为 200K。 20 轮全部发送；ContextPlan hard boundary 主动触发 maintenance；无持久化 hard-pressure audit；checkpoint 的 coveredSourceEntryRefs 始终为空。
Single plan 在 provider handler 内同时读取真实 payload token 与 getContextBreakdown()，再对齐持久化 audit。 每轮均满足 providerTokens === statusTokens === qualityGate.projectedInputTokens；wire plan 不超过 planTokenBudget。
Resume / bounded epoch 第 10 轮 flush + reload，第 11 轮继续同主题。 新 plan 记录 rebaseReason=resume；上一轮语义仍在 payload；active derived materials 不超过 1 checkpoint + 5 digest/recall；checkpoint 已吸收 digest 不在 active tail 重复。
Pass / burst / hard 普通 20-turn pass；带可覆盖旧 baseline 的 10K→18K burst；单个不可容纳的 protected current prompt。 pass 可发送；burst 保留完整 replacement 且 wire cap 生效；hard 不发送 provider request，audit 的 projected input 明确超过 limit，当前 prompt 仍在 journal 与 live agent state。
Disabled parity 同一两轮输入分别走默认 non-steady 与显式 san.contextSteady.enabled=false。 去除时间型元数据后 provider messages 等价；不写 digest / plan / checkpoint；不关闭 provider session。
