产品建议

Default 不建议把多角色设为所有任务默认开启：多角色必须在目标漂移率、错误放行率或纠偏成功率上证明增益，而不是只看 pass rate。

v0.1 Only Context steady only 模式用于隔离上下文稳态贡献，重点观察长程任务的目标保持，而不是 review 证据链数量。

Smart / Deep 建议保留异构多角色作为高风险任务、架构审查、验收报告、需要独立 review 的档位；它比同模型多角色快很多，并且产生了 15 个 worker 结果和 14 个 review 证据。

Same Model 不建议作为主推策略：同样 7/10 passed，但耗时约为单 Agent 的 n/a，token 约为 n/a。

Next 下一步优先降低 token：收紧 roleContext、减少 T08 deep 的 worker 扩散、按任务难度触发 Oracle，并补 3 轮均值/方差后再判断是否进入默认策略候选。
