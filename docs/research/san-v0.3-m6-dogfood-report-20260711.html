6. 真实 Session / Slash smoke

“真实 session”指实际构造并运行 AgentSession 的完整 prompt 生命周期，provider transport 使用 deterministic mock model，因此不依赖随机模型输出，也不写真实用户 bank。验证覆盖：

  • approved recall policy 进入真实 Context Steady recall 路径并写入 san.brain.recall audit；
  • projection blocked 后两个真实 user prompt 均继续完成；
  • blocked 状态只产生一次 UI-only notice，provider messages 不含该提示；
  • capture、activation、ContextPacket resume/rebuild 走真实 SessionManager journal；
  • /brain project 在 effective policy disabled 时不能旁路；debug 保持只读。

没有提交完整 transcript、evidence 原文、凭据、用户 home 绝对路径或 backend 地址。

7. 报告问题逐项回答

  1. 发生频次：7 个 turn 产生 7 个 Candidate；1 个 turn 选中 activation；2 次 recall audit（1 applied、1 suppressed）；5 个 turn 执行 projection，最终 6 条 projection record。
  2. 相关与跳过：Turn 4 的交付任务激活 profile；Turn 7 的 release 任务启用 risk-history recall；Turn 5 因 current-user conflict 跳过；Turn 8 因 selector mismatch 不生成 query；wrong scope/type recall items 被过滤。
  3. 安全异常：重复写、错误 recall、CAS 覆盖、审计孤儿、重复通知和 secret 泄露均为 0；唯一 blocked 是预期的人工修改 CAS 保护。
  4. Backend 边界：off/local 明确报告能力缺失；Mnemopi receipt/scope/compensation 成立；Hindsight document receipt 与受控 outage 降级成立。
  5. 阈值：不调整。candidate max=1 远低于 5，activation max=166 远低于 1200，attempt max=1 低于 3，deterministic latency 远低于 10 秒。当前数据不足以支持缩短生产网络 timeout。
  6. 最终决策：扩大内部 opt-in；默认仍关闭。
