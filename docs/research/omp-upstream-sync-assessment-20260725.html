  • 此前直接合并的尝试已经被回滚到 b8f40148f；当前同步只在独立分支进行，不再污染 main。
  • git merge-tree --write-tree --name-only main upstream/main 返回非零，并列出 59 个内容冲突；这不是自动可落地的 merge。
  • 冲突集中在 San 正在维护的运行时边界：会话、模型 registry、provider globals、工具 schema、SDK、task executor、settings 与 TUI 控制器。
