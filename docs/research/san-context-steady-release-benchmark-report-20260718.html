4. 配对分布：置信区间跨越零

由于中短任务数量多但单体成本低，L5 成本极高但样本少，整体 Median 与 Bootstrap 95% CI (15个样本) 跨越了零收益边界。不可宣称“普遍便宜”。

5. L5 深度剖析：活跃上下文 vs 原始日志

L5 证明了 Context Steady 在超长上下文（180步）中的作用：原始会话 (Raw Journal) 继续增长超过 550K，而活跃上下文 (Active Context) 被成功折叠与压缩到约 68K 以下。

6. 基础设施与统计基线声明

  • 模型与配置： Native/Steady 主模型均为 asxs/gpt-5.6-sol:xhigh，Digest 模型为 self/gpt-5.4-mini。禁用 fallback，重试上限 1。
  • Provenance： Base Commit: 3ac89d1c，Source Diff Hash: 9e2a0ead。任务与运行数据完全基于严控哈希生成。
  • 基础设施中断： 实验发生失败时直接使整个配对失效，禁止静默剔除失败次以粉饰数据。当前有 0 个最终基础设施工件无效。
  • 价格表： 输入 $5/M，输出 $30/M，缓存读 $0.5/M，缓存写 $6.25/M。此为 Runner 估算冻结价，非真实服务商账单。
