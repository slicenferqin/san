3. 新电脑恢复步骤

  1. 克隆并进入仓库：git clone git@github.com:slicenferqin/san.git && cd san。
  2. 安装依赖：bun install。
  3. 确认本机 provider 配置存在：
    • ~/.reasonix/config.json：DeepSeek worker key/model。
    • ~/.claude/settings.json：Claude supervisor base URL/key。当前实测可用模型是 claude-sonnet-4-5-20250929。
    • ~/.codex/config.toml 与 ~/.codex/auth.json：GPT commander/oracle provider 和 key。
  4. 运行本地检查：bun test packages/coding-agent/test/san-loop && bun check。
  5. 生成临时模型配置并跑真实 suite。注意：生成的 models.yml 包含真实 key，只能放临时目录，不能提交。
