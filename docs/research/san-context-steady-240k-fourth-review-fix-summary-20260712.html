2. 第四轮 Findings → 修复

P0 · Wire clamp 删 raw 后截断 replacement

删除字符级 clampRenderedPlanToBudget；只按 material 整体裁减后生成 coverage。

  • fitMaterialsToPlanBudget 逐个丢 recall → digest → checkpoint，直到 rendered shell 可放进 planTokenBudget。
  • 之后才调用 coverageForMaterials；禁止 coverage 冻结后再 slice 字符串。
  • 若空 shell 仍超极小 cap：保留无 coverage 的 shell，绝不「删 raw 却无完整 replacement」。

文件： packages/coding-agent/src/context-steady/planner.ts

合同： planner 测试「enforces planMaxTokens by dropping whole materials, not string-slicing coverage」

P0 · Hard-pressure prompt 只进 journal

拒绝路径同步 active agent messages。

  • hard_pressure 时：session journal append + agent.appendMessage（若尚未在 live state）。
  • 同会话 follow-up / 从 journal 重建后，provider payload 必须仍含 refused marker。

文件： packages/coding-agent/src/session/agent-session.ts

合同： m2「persists hard-pressure…」+「keeps refused hard-pressure prompt visible to the next same-session provider call」

P1 · Tool-loop 双计

estimate 拆成 pending / full 两种模式。

  • 首请求：mode: "pending" → [...this.messages, ...pending]。
  • Provider transform / tool-loop：mode: "full" → 只估完整 transformed messages，不再叠一层 stored history。
  • ~175K 合法 tool tail 应允许第二次 provider call；真超 burst 仍 hard_pressure。

合同： m2「does not double-count stored history when re-gating a legal tool-loop tail」+ 既有超限 re-gate 测试

P1 · 自然 topic shift

非 continuation 提示走 relevance；不依赖「new topic」短语。

  • Planner：requireRelevance = topicShift || !continuation，过滤无关 digest/checkpoint。
  • 自然换题（如第三轮原输入 compare unrelated language models）写 rebaseReason: "topic_shift" 且不注入 legacy digest。

合同： planner「drops unrelated digests on natural topic change…」

P1 · Semantic required 过宽

只保护「仍未解决」的有界集合，不用 filesTouched 永久 exact。

  • 最近 3 轮 exact + 最近 5 个非 fallback digest 的 openQuestions/risks span。
  • 不再因任意历史 filesTouched 永久保护 raw span（避免 12–20 轮无界）。
P1 · Epoch / rebase / checkpoint cap

稳定 epoch；pending reason 优先；极小 checkpoint fail-closed。

  • epochId 不再含当前 leaf（避免每轮新 epoch）。
  • Rebase reason 优先级：pending resume / budget_pressure / topic_shift 优先于 checkpoint boundary 上的旧 reason。
  • Checkpoint 在 trim 后仍超 maxTokens → 返回 null（不发超预算 coverage 权威）。

合同： context-packet「fail-closes checkpoint emission when even a minimal summary exceeds maxTokens」

P1 · SanLoop plan consumers 跨分支

SanLoop 与 commander role context 只读 active branch。

  • builtin-registry.ts：latestContextPlanRefs(getBranch())。
  • agent-session.ts：buildSanLoopRoleContext(getBranch(), …)。
P2 · 测试假阳性 / barrel
  • Dogfood：protected refs 必须 branchIds.has(ref)，去掉 || ref.length > 0。
  • Barrel：session 与 packet 的 collectDigestRefs 消歧义；packet 仅 named re-export 非重复符号。
