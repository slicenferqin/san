会话级子代理模型路由

新增 /subagent，在不修改全局或项目配置的前提下，为当前会话中绑定 @task 角色的子代理指定模型与思维强度。状态写入会话日志，随恢复和分支正确还原，不污染主代理模型。

1. 问题与决策

现有 modelRoles.task 与 task.agentModelOverrides 适合全局或项目默认值，但不适合临时会话实验。直接改 Settings 的运行时覆盖层会影响共享该实例的其他会话；外部编辑配置还可能因长会话未热重载而保持旧值。

决策：路由覆盖属于 AgentSession，不是 Settings。使用非上下文会话条目持久化，TaskTool 在每次派生子代理时从当前分支解析最新值。

目标

  • 当前会话即时切换 @task 子代理模型，支持 provider/model:effort。
  • 恢复、分叉和树导航均遵循所在分支的最新覆盖。
  • 会话覆盖高于全局/项目的 per-agent override，但不改动主代理模型。
  • 模型选择和思维强度在写入前完成解析与校验。

非目标

  • 不把所有专家代理强制切到同一模型；@smol、@slow、@designer 等角色保持原路由。
  • 不实现运行时故障转移、配置热重载或每次 TaskTool 调用的显式 model 字段。
  • 不写入 ~/.san/agent/config.yml 或项目 .san/config.yml。

2. 用户接口

命令TUIACP/文本模式
/subagent打开模型选择器；选择模型和 effort 后写入会话覆盖显示当前覆盖状态
/subagent status显示当前 @task 会话覆盖；未设置时显示配置路由仍生效
/subagent clear写入显式清除事件，恢复项目/全局配置路由
/subagent cpa/kl/deepseek-v4-flash:max解析为具体模型，验证 max，再写入规范化 selector
 
/subagent cpa/kl/deepseek-v4-flash:max
# Task-role subagent model: cpa/kl/deepseek-v4-flash:max

/subagent clear
# Task-role subagent model override cleared.

校验边界：用户显式指定的 effort 若不在模型支持集合中，命令报错，不静默降级或钳制。未带 effort 时使用代理定义或模型解析得到的既有默认规则。

3. 路由优先级

1单次 task.model
未来/上游能力
2会话 /subagent
3task.agentModelOverrides
4代理定义 @task
5主会话模型回退

本次本地实现覆盖第 2–5 层；当前分支尚无上游已合并的 per-call task.model wire 字段，因此第 1 层仅保留为兼容方向。

会话覆盖只在代理定义的 model 是单一 @task（兼容旧写法 pi/task）时生效。显式绑定其他角色或具体模型的专家代理不受影响。

4. 会话状态模型

{
  "type": "custom",
  "customType": "subagent_model_override",
  "data": {
    "role": "task",
    "selector": "cpa/kl/deepseek-v4-flash:max"
  }
}

清除使用同一事件结构并令 selector: null。读取算法沿当前 branch 从后向前找到该 role 的第一条合法事件；因此：

  • 恢复：日志天然携带状态，无额外设置文件。
  • 分支：子分支继承分叉点以前的覆盖；分叉点以后的兄弟分支修改互不干扰。
  • 清除：显式 null 阻断更早的覆盖，不能用“没有条目”表达。
  • 上下文：custom 条目不进入 LLM 上下文，不消耗提示词。

禁止复用 model_change：它参与主模型恢复和 fallback role 推断，会把子代理覆盖误当成主会话模型切换。

5. 实现切面

区域改动不变量
session新增 branch-aware 的读取/追加 helper；AgentSession 暴露只读 getter不进入 LLM context，不修改 Settings
toolsToolSession 增加可选 getter现有测试/嵌入方无需实现
task在模型 pattern 解析前注入会话覆盖只覆盖单一 @task 绑定；session > config
slash command注册 /subagent，支持 status/clear/selector规范化具体 selector，拒绝未知模型和不支持 effort
TUI复用 Model Hub 的模型与 effort 选择流程选择结果写子代理状态，不触发主模型切换

6. 验收与回归

  1. 设置 /subagent cpa/kl/deepseek-v4-flash:max 后，下一次 @task spawn 的 modelOverride 使用该 selector，即使配置存在不同的 per-agent override。
  2. @slow 等专家代理不受覆盖。
  3. /subagent status 能读取刚写入状态；clear 后回到配置路由。
  4. 会话恢复、分支和清除遵循“当前 branch 最新合法事件”。
  5. 未知模型、非法 effort、模型不支持的显式 effort 均不写入条目。
  6. 运行 coding-agent 的聚焦测试、bun check，再通过 CLI smoke 场景确认命令和下一次子代理派生。
