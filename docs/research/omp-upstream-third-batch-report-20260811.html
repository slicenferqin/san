1. 交付结论

结论：第三批 22 个实现、测试与 changelog 文件已完成 San 结构适配；仓库检查和四个相关包的全量回归均通过。未吸收开放 PR，也未把 Agent Hub、native fuzzy-find 或 RPC v3 混入本批。
  • 系统 Chromium 候选必须是普通可执行文件，并通过有界 --version 探针确认 Chromium、Chrome 或 Edge 身份；显式 PUPPETEER_EXECUTABLE_PATH 仍保持最高优先级。
  • 浏览器探针 3 秒触发终止、3.5 秒封顶输出读取，并在读取 stdout 尾部后再检查退出状态，既不会无限挂起，也不会竞速误拒绝正常浏览器。
  • 真正的订阅、账号和简中额度耗尽会轮换兄弟凭证；计划分钟限额、并发、速率和频率上限保持瞬时退避，不消耗健康账号。
  • 账号级 403 与无状态码 Connect 尾帧可直接轮换；非计费并发 403 不进入 auth rotation，HTTP 402 的计费语义仍优先。
  • “Your limit will reset in …” 重置窗口优先于短时 retry hint，并透传到凭证封禁时长；coding-agent 对并发上限至少退避 5 秒，且不删除仍有效的 Copilot 凭证。
  • 扩展 module import 并行执行，factory/bind 严格按输入顺序串行；单个导入或 factory 失败不阻断批次，provider 注册回滚合同不变。
